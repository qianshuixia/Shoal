# 变更与文件面板（Inspector）需求规格说明

本文档定义 Shoal「变更 / 文件」右侧面板（定位：**Agent 验收与快改台**）的布局、交互联动、功能边界、并发安全与验收标准。基础工作台能力见 [v1-spec.md](v1-spec.md)。

---

## 1. 背景与定位

在 CLI 终端驱动的 Agent 工作流中，用户最频繁的两个痛点是：

1. **看不清改了什么**：Agent 跑完进入「待验收」或中途停下时，终端里只有滚动日志，无法直观看到当前项目到底改了哪几个文件、具体增删了哪些行。
2. **顺手小改成本高**：改一行 `.env`、修一个文案错字、看一眼生成的 `docs/*.md` 或截图，每次都要切出工作台去打开外部重型 IDE。

**定位原则**：

- 做成**轻量、零干扰的「Agent 验收与快改台」**，绝不演化成臃肿的全功能 IDE（不内置 LSP 语言服务器、调试器、构建系统或复杂 Git 分支图）。
- 遵循 Shoal 零闪烁铁律：**在右侧面板内的一切操作（切标签、展开目录、看 Diff、切编辑、保存、弹冲突提示），左侧终端 `.pane-body` 几何尺寸保持绝对静止（0 次额外 PTY resize）**。

---

## 2. 布局模型：三态共享右槽位

保留双屏能力，不塞三栏（避免终端被挤窄导致 TUI 折行错乱），将顶栏布局切换升级为三态互斥分段控件：

| 模式 | 布局结构 | 适用场景 |
| --- | --- | --- |
| **单屏** (`1`) | `[ 侧栏 \| 终端 A (100%) ]` | 专注单个复杂任务对话 |
| **双屏** (`2`) | `[ 侧栏 \| 终端 A (50%) \| 终端 B (50%) ]` | 两个 Agent 并排协作 / 对照 |
| **变更/文件** (`inspect`) | `[ 侧栏 \| 终端 A \| 变更与文件面板 ]` | 边看终端边审 Diff、查改项目文件 |

### 布局与交互细节

1. **快捷键**：`Alt+E` 一键开关「变更/文件」模式（在终端聚焦时同样生效）：
   - 当前不是 `inspect` 时：记住原布局（单屏或双屏，若双屏则保留当前聚焦面板的会话在左侧），切入 `inspect`；
   - 当前已在 `inspect` 时：按 `Alt+E` 或点面板右上角 `×`，恢复单屏（或直接点顶栏 `单屏` / `双屏` 切回对应模式）。
2. **可拖拽分隔条**：左侧终端与右侧面板之间提供竖向拖拽条，支持自由调整右侧面板占比（百分比持久化于 `localStorage` `wb.inspectSplit`，范围 `28%`–`68%`，默认 `50%`，双击恢复 `50%`）。拖拽过程中依赖 `terms.ts` 既有的 `100ms` 防抖机制，松手后终端才发送一次最终 `resize`。
3. **项目跟随**：
   - 默认自动跟随左侧终端当前聚焦任务所属的项目（`project`）；
   - 若用户从侧边栏点击任意项目的分支徽章（`branch · N`），面板打开并锁定查看该项目（当用户再次点击切换任务行时重新跟随当前任务项目）；
   - 按 `projectId` 在内存中记住各自上次打开的文件路径与激活标签（`变更` / `文件`），来回切任务不丢上下文。

## 3. 核心入口联动

1. **顶栏分段按钮**：`[ 单屏 | 双屏 | 文件 ]`（悬停提示说明 `变更与文件（Alt+E）`，若当前项目有未提交改动，可在按钮旁或面板内直观看到改动数）。
2. **侧边栏 Git 分支徽章点击**：点击项目头部的 `main · 3` 胶囊（`e.stopPropagation()`，不影响折叠箭头与项目名点击折叠），直接展开右侧面板并定位到该项目的 **「变更」** 标签。
3. **终端内文件路径点击直达**：
   - 点击终端输出中的本地文件链接（如 `G:\Workspace\app\src\auth.ts:42:5` 或 `file:///.../README.md#L18`）时：
   - 若目标文件位于工作台**已登记的某个项目目录内**，且后缀/类型为可检视的文本、代码、Markdown 或图片文件，则**直接在右侧面板打开该文件并滚到目标行高亮**，不再强制跳出工作台；
   - 面板工具栏保留 **「在外部编辑器打开」** 按钮（调用既有 `POST /api/open` 打开 VS Code / Cursor 并跳到当前光标行）；
   - **项目目录之外**的独立文件、目录、`.exe` 可执行文件等，完全保持既有 `POST /api/open` 行为不变。

## 4. 面板结构与功能边界

右侧面板顶栏包含：
- 标签切换：**`变更 (N)`** | **`文件`**（当首次为某项目打开且 `dirty > 0` 时默认激活 `变更`，否则默认激活 `文件`）
- 当前项目名称与分支标识（受「隐私」模式 `data-private` 保护）
- 手动刷新按钮 `↻`、「在外部编辑器打开」按钮、关闭按钮 `×`

### 4.1 「变更」标签（Git 工作区审阅与快改）

- **左侧/上方可折叠改动列表**：
  - 使用 `git --no-optional-locks` 读取工作区状态（绝不在 `.git/index.lock` 上与正在运行的 Agent 抢锁）；
  - 展示所有未提交文件：状态徽章（`M` 修改、`A` 新增、`D` 删除、`R` 重命名、`U` 冲突、`?` 未跟踪）、相对路径、`+新增 / -删除` 行数统计（兼容尚无首个 commit 的新仓库）；
  - 单文件 **「放弃改动」** 按钮（悬停显示，带二次确认弹窗）：已跟踪文件恢复至 `HEAD`，未跟踪文件（`?`）经确认后从磁盘移除，操作后立即广播最新 Git 状态。
- **右侧主视口**：
  - 默认展示 **Unified Diff（单栏行内红绿对比）**（基于 CodeMirror 6 `@codemirror/merge` `unifiedMergeView`）：单栏对比在半屏宽度下代码不折行，上下文清晰；
  - 视口顶部文件栏提供 **`[ 对比 | 编辑 ]`** 一键切换：发现小问题切到「编辑」直接修改，`Ctrl+S`（或点「保存」按钮）落盘并刷新 Diff；已删除文件（`D`）仅展示只读删除 Diff；未跟踪新文件（`?`）可直接检视全文与编辑。

### 4.2 「文件」标签（项目浏览与轻量编辑）

- **左侧惰性文件树**（可一键收起以腾出全宽阅读空间）：
  - 仅在展开目录时请求该层子项，不在打开项目时全量扫描磁盘；
  - 目录置顶、按名称不区分大小写排序；
  - **对 Agent 排障友好的可见性**：**默认展示 `.env`、`.env.local`、`.gitignore`、`.github` 等点文件**；对 `node_modules`、`dist`、`build`、`target`、`.next`、`.turbo` 等重型产物目录置灰折叠（仍允许手动点开排查），隐藏 `.git` 内部对象目录以防误触；
  - 同步标记有 Git 未提交改动的文件状态色点。
- **快速搜文件（`Ctrl+P`）**：
  - 当焦点位于右侧面板内时，按 `Ctrl+P`（或点文件树顶部搜索按钮）弹出项目内文件名模糊搜索框，回车直达目标文件（不与全局 `Alt+K` 任务搜索冲突）。
- **主视口能力**：
  - **文本/代码编辑（CodeMirror 6）**：行号、折叠、括号匹配、`Ctrl+F` 页内搜索替换、`Ctrl+S` 保存、未保存圆点 `●`、语法高亮（TS/JS/JSX/TSX、JSON、CSS、HTML、Markdown、Python、Rust、YAML 等）；字号随全局缩放 `wb.scale` 联动，字体与终端一致采用 `"Maple Mono NF CN"` 优先等宽栈。
  - **Markdown 阅读模式**：打开 `.md` / `.mdx` 文件时，文件栏提供 **`[ 预览 | 源码 ]`** 切换（默认 `预览` 或记住切换选择）；**安全铁律**：严禁执行或原样注入未清洗的原始 HTML，彻底杜绝本地端口 XSS。
  - **图片内联预览**：`.png`、`.jpg`、`.jpeg`、`.gif`、`.webp`、`.bmp`、`.svg` 直接渲染缩放预览与文件大小信息（服务端原始流仅白名单放行图片并加严格 `Content-Security-Policy: default-src 'none'` 响应头）。
  - **大文件与二进制保护**：超过 `2 MB` 的文件或含 `\0` 字节的二进制文件不加载进编辑器，显示友好提示与文件体积，引导点击「在外部编辑器打开」。

## 5. 并发与安全边界

### 5.1 磁盘并发与乐观锁（防止覆盖 Agent 改动，也防止冲掉用户手改）

终端里的 Agent 随时可能修改磁盘上的同一个文件：

1. **保存乐观锁（`expectedMtimeMs`）**：
   - 前端读取文件时记录服务端返回的 `mtimeMs`；
   - `PUT /api/projects/:id/file` 携带 `expectedMtimeMs`。若磁盘当前 `mtimeMs` 已变化且磁盘内容与预期不一致，服务端拒绝静默覆盖并返回 `409 Conflict`（附带最新 `mtimeMs`），除非用户显式确认强制覆盖（`force: true`）。
2. **外部修改自动感知**：
   - 当 Agent 回合结束（`Stop` hook 立即触发 Git 刷新）、WebSocket 收到项目 `git` 更新、窗口重新聚焦或面板打开期间轻量轮询检测到当前打开文件的 `mtimeMs` 发生变化时：
   - **若编辑器无未保存修改（clean）**：静默热重载最新内容 / Diff，用户实时看到 Agent 刚改完的结果；
   - **若编辑器有未保存手改（dirty）**：**绝不自动覆盖用户草稿**，在文件栏下方弹出非侵入冲突提示条：`磁盘上的文件已被外部更新` —— 提供 **`[重新加载磁盘版本]`** 与 **`[保留我的修改并覆盖]`** 两个明确动作。
3. **离开未保存提示**：当前文件有未保存修改时，切换文件或关闭面板前提示确认（或自动保留内存草稿/确认丢弃），防止误关丢字。

### 5.2 路径越界与来源校验

- 所有新增写/删接口（保存文件、放弃改动）均复用 `server/http.ts` 同源校验（`sameOrigin`）；
- 所有文件路径参数必须经 `resolveProjectPath(project.path, relPath)` 校验：解析 `fs.realpathSync(project.path)` 与目标真实父路径，**严禁 `..` 路径穿越、盘符越界、UNC 路径、指向项目外的符号链接，以及对 `.git/` 内部元数据目录的直接写入或删除**。

## 6. 后端接口契约（`/api/projects/:id/...`）

| 方法与路径 | 用途 | 关键参数与返回 |
| --- | --- | --- |
| `GET /api/projects/:id/changes` | 获取项目 Git 分支与全部未提交改动列表 | 返回 `{ git: GitInfo \| null, files: ChangedFile[] }` |
| `GET /api/projects/:id/diff?path=<rel>` | 获取单文件 `HEAD` 与工作区对比数据 | 返回 `{ path, status, base, head, binary, tooLarge, size, mtimeMs }` |
| `GET /api/projects/:id/tree?path=<relDir>` | 惰性读取单层目录条目（附带 Git 脏标记） | 返回 `{ path, entries: TreeEntry[] }` |
| `GET /api/projects/:id/files` | 获取项目内可搜索的相对文件路径列表（供 `Ctrl+P`） | 返回 `{ files: string[], truncated: boolean }` |
| `GET /api/projects/:id/file?path=<rel>` | 读取单文件文本内容或元信息（支持仅查 `stat=1`） | 返回 `FilePayload`（`text \| image \| binary \| too_large \| missing`） |
| `GET /api/projects/:id/raw?path=<rel>` | 安全流式读取项目内图片供 `<img>` 预览 | 仅限图片后缀，附 `CSP: default-src 'none'` + `X-Content-Type-Options: nosniff` |
| `PUT /api/projects/:id/file` | 保存文本文件（带乐观锁） | Body `{ path, content, expectedMtimeMs?, force? }`；冲突返回 `409` |
| `POST /api/projects/:id/discard` | 放弃单文件未提交改动 | Body `{ path }`；恢复已跟踪文件或删除未跟踪文件，触发 Git 广播 |

同时增强 `server/http.ts`：在 Agent 会话触发 `Stop` hook 时立即异步刷新对应项目的 Git 状态，无需等待 10 秒轮询周期。

## 7. 验收标准

1. **三态切换与拖拽流畅**：顶栏 `[ 单屏 | 双屏 | 文件 ]` 与 `Alt+E` 切换正确，拖拽中间分隔条可平滑调整宽度且持久化，双击恢复默认。
2. **入口联动闭环**：点侧栏 `branch · N` 徽章直达该项目「变更」标签；点终端内项目文件链接（含 `:line` / `#Lline`）直接在右侧打开并定位行；项目外链接与 `.exe` 仍走既有外部打开逻辑。
3. **Git 审阅与快改可用**：正确展示修改（`M`）、新增/未跟踪（`A`/`?`）、删除（`D`）及增删行数；Unified Diff 清晰可读，切「编辑」修改并 `Ctrl+S` 保存后磁盘内容与 Diff 同步更新；单文件「放弃改动」可安全还原。
4. **文件浏览与多格式预览**：惰性目录树可见 `.env*`、弱化 `node_modules`；`Ctrl+P` 快速定位文件；Markdown 预览美观且过滤一切 XSS 脚本；图片正常内联预览；`> 2 MB` 与二进制文件安全拦截。
5. **并发安全无损**：Agent 外部改盘时，干净编辑器自动热更新，未保存编辑器弹出冲突条且不丢草稿，`409` 乐观锁保护生效。
6. **零终端闪烁不变量**：右侧面板已打开状态下，切换标签、展开目录、切换文件、切换 Diff/编辑、保存、出现冲突提示条，左侧终端 `.pane-body` 宽高变化为 `0 px`，PTY `resize` 次数为 `0`。
